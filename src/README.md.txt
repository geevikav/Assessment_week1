# Employee Analysis Project

## Setup Steps
1. Install Python 3.13.
2. Create a virtual environment.
3. Install requirements using pip install -r requirements.txt.
4. Install Jupyter Notebook.
5. Open employee_analysis.ipynb.

## Findings
1. Employee data was loaded successfully.
2. IT department has 4 employees.
3. HR department has 2 employees.
4. Sales department has 2 employees.
5. Department-wise average salary was calculated and visualized.
